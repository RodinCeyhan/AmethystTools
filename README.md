# ✨ AmethystTools

A customizable Paper/Folia plugin that adds powerful 3x3 amethyst mining tools with GUI support.

Inspired by custom tool systems used on popular SMP servers, AmethystTools enhances survival gameplay with smarter and faster mining mechanics.

---

## 📦 Version Information

Starting with version `1.4`, the plugin is distributed as a single JAR file.

- Copper tools are **not available** in Minecraft `1.21 - 1.21.8`
- Copper tools are available in `1.21.9+` and `26.1.X`

---

## ⛏️ Commands

### `/amethysttools <material> <type>`
Opens the AmethystTools menu.

### `/amethysttoolsreload`
Reloads the plugin configuration.

### `/amethysttoolsgive <player> <material> <type>`
Gives Amethyst Tools to a player.

## ✨ Features

### ⛏️ 3x3 Area Mining
- Break multiple blocks at once
- Supports horizontal and vertical mining
- Automatically adjusts mining direction based on where the player is looking

### 🪓 Multiple Tool Variants
Includes pickaxes, shovels, and axes for:
- Wooden
- Stone
- Iron
- Copper
- Golden
- Diamond
- Netherite

### ⚡ Smart Mining System
- Detects player direction automatically
- Supports upward and downward mining
- Smooth and optimized block breaking

### 🧩 Fork Optimized
Optimized for:
- Paper
- Folia
- Folia-based server software

---

## 📥 Installation

1. Download the plugin from Modrinth or SpigotMC
2. Place the JAR file into your server's `plugins` folder
3. Restart the server
4. Configure the plugin if needed

---

## 🔑 Permissions
